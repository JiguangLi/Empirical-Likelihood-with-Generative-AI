# Empirical Likelihood with Generative AI


This repo contains our official implementation of a nonparametric Bayesian framework based on exponentially tilted empirical likelihood. This Bayesian formulation is particularly appealing in settings where prior information is more naturally specified on the observables rather than on the underlying parameters. Such settings arise in the presence of auxiliary data sources or synthetic data generated by modern generative AI models. Inference proceeds by projecting posterior draws from a Dirichlet process onto the moment-restricted model, yielding a computationally efficient procedure that is naturally amenable to parallelization.

## Installation

We recommend creating a fresh conda environment before installing the package.

```bash
conda env create -f environment.yml
conda activate EL
```

Then install the local package in editable mode from the root directory of this repository:

```bash
pip install -e .
```

After installation, the package can be imported in Python as

``` python
import EL
```

The editable installation is useful for development because changes made to the source code under src/EL/ are immediately reflected without reinstalling the package.

## Repo Direction

- Source code is located in ```/src```:
    - ```GenELV2.py```: handle unconditional moment restrictions.
    - ```ConditionalGenELV2.py```: handle conditional moment restrictions.
    - ```MixedConditionalGenELV2.py```: handle mixed conditional and unconditional moment restrictions.
    - ```StructuralBETELV2.py```: handle structural function recovery.

- All experiments are located in ```/markdowns```
    - For a quick experiment for demo, we recommend you checkout  ```/markdowns/10-21-25-vanilla-el/experiment_v2.ipynb``` for simple and fast examples, including inference in mean, over-identified IV, and ligistic regression.

## Experiment Replications

- To replicate Section 5.1 of the paper. Go to  ```/markdowns/10-21-25-vanilla-el/section5.1_experiment.ipynb```
- To replicate Section 5.2 of the paper. Go to  ```/markdowns/12-30-25-cmr-simulations```:
    - Run ```main.py``` to save results
    - Run ```simulations.ipynb``` to replicate the tables in the paper.
- To replicate Section 5.3 of the paper. Go to  ```/markdowns/01-02-26-asset-pricing```:
    - Data is named: ```asset_pricing_data.csv```. Alternatively, you can also run ```create_ap_data.Rmd``` to download the data from the R package.
    - Run ```main.py``` to replicate experiments and save results.
    - Run ```asset_pricing.ipynb``` to visualize tables for the paper.
- To replicate Section 5.4 of the paper. Go to  ```/markdowns/01-05-ate``:
    - Processed Data is named: ```lottery_processed.csv```. Alternatively, you can also run ```extract_lottery_data.Rmd``` to process data from scratch. The raw data is ```lottery.RData```
    - Run ```main.py``` to replicate experiments and save results.
    - Run ```ate.ipynb``` to visualize results.
- To replicate Section 6.1 of the paper. Go to  ```/markdowns/02-26-gen-ai-finance``:
    - Note the data is proprietary, but you can query them with a valid WRDS account.
    - Run ```s01_query_wrds_data.ipynb``` to query stock price and financial news data.
    - Run ```s02_process_news_data.ipynb``` to process and clean financial news data.
    - In the ```/news_generation_code``` folder, you can find two seperate scripts that prompt OpenAI API to generate synthetic news return labels or the news itself.
        - ```generate_synthetic_label_batch.py```: only generate synthetic labels conditional on the real news.
        - ```generate_synthetic_news_batchv2.py```: generate both synthetic news and synthetic labels together.
    - Run ```s08_mc_simulations_large.py``` to save results.
    - Run ```evaluate_mc_simulations.ipynb``` to visualize tables and results used in the paper.
- To replicate Section 6.2 of the paper. Go to  ```/markdowns/03-17-iv-simulation-v2``:
    - Raw data is ```Engel95.csv```
    - Run ```engel95_prepare_training_synthetic_data.py``` to prompt ChatGPT to generate synthetic data:
        - Alternative, you can use the folder ```output_engel95_100``` and ```output_engel95_400``` directly.
    - Run ```s100_engel95_simulation_all.py``` to replicate experiments for N=100 case
    - Run ```convex_hull_simulation.py`` to convex hull diagnosis.
    - Run ```evaluate_final.ipynb``` to visualize the tables and graphs in the paper.
